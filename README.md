
# Notes — Android-приложение для заметок

## Описание

Notes — мобильное приложение для создания, просмотра и редактирования заметок. Разработано в Android Studio с использованием Kotlin и XML.

## Функциональность

- Просмотр списка заметок
- Создание новых заметок
- Просмотр содержимого заметки
- Редактирование существующих заметок
- Проверка заполнения полей
- Логирование жизненного цикла Activity и действий пользователя

## Технологии

- Kotlin
- Android SDK
- XML Layouts
- Android Studio
- Gradle

## Структура приложения

- MainActivity — главный экран со списком заметок
- DetailActivity — просмотр выбранной заметки
- EditNoteActivity — создание и редактирование заметок
- NoteStorage — хранение заметок в оперативной памяти

## Навигация

Переходы между экранами реализованы с помощью явных Intent. Индекс выбранной заметки передаётся через putExtra().

## Требования

- Минимальная версия Android: 8.0 (API 26)
- minSdk: 26
- targetSdk: 37
- compileSdk: 37
- Язык программирования: Kotlin
- Интерфейс: XML Views
- Java Compatibility: 11

## Запуск проекта

1. Скачать или клонировать репозиторий.
2. Открыть проект в Android Studio.
3. Дождаться синхронизации Gradle.
4. Запустить приложение на эмуляторе или Android-устройстве с Android 8.0 и выше.
## Логирование

Для регистрации событий используется Android Log. Приложение записывает события жизненного цикла Activity, нажатия кнопок и ошибки ввода.

Файл с примерами логов: logs.txt

## Особенности

Заметки хранятся в оперативной памяти. После завершения процесса приложения пользовательские изменения пропадают.
